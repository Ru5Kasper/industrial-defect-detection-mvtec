# Industrial Defect Detection with MVTec AD

Учебный проект по поиску и локализации промышленных дефектов на датасете [MVTec AD](https://www.mvtec.com/research-teaching/datasets/mvtec-ad).

## Цель

Обучить алгоритм только на изображениях исправных объектов, затем определять наличие дефекта на новом изображении и показывать его расположение тепловой картой и бинарной маской.

Основной метод — PatchCore. В качестве воспроизводимого baseline планируется PaDiM. Оценка проводится на стандартном тестовом разбиении MVTec AD.

## Датасет

MVTec AD содержит более 5 000 изображений в 15 категориях объектов и текстур. Для каждой категории используются:

- `train/good` — исправные изображения, единственный источник данных для обучения;
- `test/good` и `test/<defect_type>` — нормальные и дефектные тестовые изображения;
- `ground_truth/<defect_type>` — попиксельные маски дефектов для оценки локализации.

Датасет не хранится в репозитории. Скачайте его с [официальной страницы MVTec](https://www.mvtec.com/research-teaching/datasets/mvtec-ad) и распакуйте в `data/mvtec_ad/`.

## Быстрый старт

```bash
git clone <REPOSITORY_URL>
cd industrial-defect-detection-mvtec
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

Пилотные эксперименты запускаются на категориях `bottle`, `cable` и `carpet`.

```bash
# Обучение: используются только data/mvtec_ad/<category>/train/good
python -m src.train_padim --config configs/padim.yaml

# Оценка на штатном test и сохранение heatmap, масок и метрик
python -m src.evaluate_padim --config configs/padim.yaml
```

Статистики PaDiM сохраняются в `artifacts/padim/`, визуализации — в
`results/figures/padim/`, а метрики добавляются в `results/metrics.csv`.

## Метрики

- Image-level AUROC — качество определения дефектного изображения.
- Pixel-level AUROC — качество пиксельной карты аномалий.
- AUPRO/PRO — качество локализации дефектов.
- Время инференса — практическая скорость метода.

## Структура

```text
configs/                 конфигурации экспериментов

scripts/                 вспомогательные сценарии
src/                     загрузка данных, обучение, инференс, оценка
results/                 таблицы метрик и визуальные результаты
reports/                 исходники и итоговый отчёт
```

## План экспериментов

1. Проверить структуру датасета, размеры изображений, баланс тестовых типов дефекта и связь изображений с масками.
2. Выполнить PatchCore на трёх пилотных категориях.
3. Запустить PaDiM в идентичных условиях.
4. Сравнить метрики по категориям, проанализировать ложные срабатывания и пропуски.
5. Расширить лучший вариант на полный набор категорий при наличии вычислительных ресурсов.

## Воспроизводимость

Каждый эксперимент должен иметь конфигурационный файл, фиксированный seed, сохранённые метрики в `results/metrics.csv` и примеры предсказаний. Веса моделей при необходимости размещаются во внешнем хранилище, а ссылка добавляется в этот файл.
