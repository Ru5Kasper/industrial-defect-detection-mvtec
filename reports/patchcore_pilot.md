# PatchCore — пилотный эксперимент

> Статус: код подготовлен; запуск на реальном MVTec AD ещё не выполнен. Численные результаты намеренно не приведены до запуска на датасете.

## Метод

Реализована собственная прозрачная версия PatchCore. Замороженный ImageNet ResNet-18 извлекает признаки layer2 и layer3. Карта layer3 интерполируется к пространственному размеру layer2; признаки конкатенируются и проходят локальную агрегацию average pooling 3×3. Все патчи из нормальных обучающих изображений формируют кандидатов в memory bank. Greedy k-center coreset уменьшает банк до заданной доли/лимита. Для каждого тестового патча находится ближайший нормальный дескриптор; расстояния образуют anomaly map, а максимум карты используется как image score.

## Протокол

- Пилотные категории: bottle, cable, carpet.
- Вход: RGB, 256×256, ImageNet mean/std.
- Seed: 42.
- Обучение использует только train/good.
- Официальные test и ground_truth используются только для итоговой оценки.
- Порог бинарного решения калибруется как 99.5-й процентиль image scores на train/good.
- AUROC/AUPRO считаются по непрерывным картам и image scores.
- AUPRO использует дискретизацию 300 порогами до FPR=0.30; это приближение, а не точная интеграция по всем уникальным score values.

## Конфигурация

Основные параметры заданы в `configs/patchcore.yaml`: coreset_ratio=0.01, max_bank_size=10000, nn_chunk_size=2048, batch_size=8 при обучении. Backbone — ResNet-18 с ImageNet1K_V1; слои — layer2 и layer3.

## Ограничения и дальнейшие проверки

Необходимо выполнить запуск на реальном датасете, проверить число файлов и масок, сравнить image-level и pixel-level scores, визуально проверить примеры, повторно загрузить сохранённую модель и сравнить scores.
